# Projet_econometrie
Analyse afin de savoir s’il il y’a un lien entre le salaire moyen d’un club de foot et sa performance. Analyse sur les clubs de Ligue 1 sur l’année 2024-2025 

## Objectif
Étudier l'impact du salaire sur la performance.

## Méthodologie
- Régression linéaire simple
- Tests de significativité individuel et global
- Test d’hétéroscédasticité

## Outils
- python
- Excel
